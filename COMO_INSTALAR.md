# 📱 Como Gerar e Instalar o StockUp no Celular

---

## 1. Onde Fica o Arquivo APK no Computador?

Depois de gerar o projeto, o arquivo `.apk` fica salvo exatamente neste caminho dentro do seu projeto:

```text
StockUp\app\build\outputs\apk\debug\app-debug.apk
```

---

## 2. Como Gerar o APK pelo Android Studio

1. Abra o projeto no **Android Studio**.
2. No menu superior, clique em:  
   **`Build`** ➔ **`Build Bundle(s) / APK(s)`** ➔ **`Build APK(s)`**.
3. Aguarde o aviso no canto inferior direito informando que o APK foi gerado.
4. Clique em **`locate`** na notificação para abrir a pasta automaticamente no seu computador.

---

## 3. Em Qual Pasta Colocar no Celular (Via Cabo USB)?

1. Conecte seu celular ao computador usando o **cabo USB**.
2. No celular, selecione a opção **"Transferência de arquivos / MTP"** na barra de notificações.
3. Abra o **Este Computador (Meu Computador)** e acesse o armazenamento do seu celular.
4. Copie o arquivo `app-debug.apk` e cole dentro da pasta:
   - 📂 **`Download`** (ou **`Downloads`**) do seu celular.

---

## 4. Como Instalar no Celular

1. No celular, abra o aplicativo **Meus Arquivos** (ou **Arquivos / File Manager**).
2. Vá até a pasta **Downloads**.
3. Toque no arquivo **`app-debug.apk`**.
4. Se o celular pedir permissão para *"Instalar aplicativos desconhecidos"*, confirme em **Permitir**.
5. Clique em **Instalar** e abra o **StockUp**! 🎉
